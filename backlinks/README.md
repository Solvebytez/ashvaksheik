## Loop

Statuses: `RESEARCHED` → `READY FOR OWNER` → `APPROVED` → `DONE BY RIO` → `LINK LIVE` / `REPLIED` / `NO RESPONSE` → `FOLLOW-UP READY` (max 1) → `CLOSED` / `DROPPED`.

1. **Researcher** finds targets, verifies they are live and relevant, writes full listing copy or outreach draft, sets the item `READY FOR OWNER` in `OUTCOMES.md`, and stops.
2. Every item has a **Needs from owner:** line in plain words. Never invent a contact.
3. **Rio** tells the owner what is waiting. When the owner approves, Rio marks `APPROVED` in `OUTCOMES.md`.
4. After approval, **Rio** submits / sends and logs the outcome. The researcher never executes.
5. On every run, read `OUTCOMES.md` first. Never redo `DONE`, `CLOSED`, or `DROPPED`. Prepare at most one follow-up draft when due.
6. Batches of **3 targets** per cycle, best first: Tier A listings → Tier B pitches → Tier C resource pages.
7. Never buy links, never offer swaps, never use PBNs. Never claim partnership with Follow Up Boss, Zillow, Anthropic, OpenAI, or Meta. Preconstruction **ads** stay on **preconstruction.ca** — not this name domain / Re/Max.
